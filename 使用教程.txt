================================================================
  GhostReg — JetBrains 账号全自动注册机 — 使用教程
================================================================

【这个工具做什么】

一键批量注册 JetBrains 账号，全程全自动（含验证码自动过），无需任何手动操作。
注册完还能一键给所有账号绑银行卡。

八大功能：
  1. 全自动注册（浏览器版）：弹浏览器 → 自动填邮箱 → 打码平台过验证码 → 接码+填密码 → 注册完成
  2. 手动注册（浏览器版）：不想用打码平台？不勾选全自动即可，只需手动过验证码
  3. 协议注册机：纯 HTTP 请求，不弹浏览器，单号 17-30 秒，比浏览器版快 5-10 倍
  4. CF 动态 IP 代理池：免费 Cloudflare Workers 代理，突破单 IP 限频，20 并发 100% 成功
  5. 协议登录（新！推荐）：纯 HTTP 登录 + Cookie 注入浏览器，15 并发秒级完成
  6. 浏览器登录：自动化填表单点按钮登录，较慢但兼容性好，并发数 1-15 可配
  7. 自动跳转绑卡页：注册/登录后自动跳到 tokens 页，选国家，弹出 Add credit card（可选）
  8. 一键填卡：在已打开的浏览器中自动填写银行卡信息 + 一键确认


================================================================
  第一步：准备工作
================================================================

【1. 安装 Python】

需要 Python 3.10 或更高版本。

下载地址：https://www.python.org/downloads/

安装时一定要勾选 "Add Python to PATH"（很重要！）

安装完后打开 CMD 验证：

  python --version

能看到版本号就说明安装成功了。


【2. 安装浏览器】

需要以下浏览器之一（程序会自动检测路径）：

  - Google Chrome（推荐）：https://www.google.com/chrome/
  - Microsoft Edge（Windows 自带，不用额外装）


【3. 网络环境】

需要能访问以下网站：

  - account.jetbrains.com（JetBrains 注册页）
  - vip.215.im（YYDS Mail 临时邮箱）
  - www.google.com（reCAPTCHA 验证码）

需要开梯子（代理/VPN）。


【4. 获取 YYDS Mail API Key（免费，只需一次）】

GhostReg 使用 YYDS Mail 临时邮箱服务来接收注册验证码。
每个用户需要自己注册一个 YYDS Mail 账号，获取免费的 API Key。

步骤：
  1. 打开 https://vip.215.im/login
  2. 注册/登录（支持 GitHub 一键登录）
  3. 登录后打开 https://vip.215.im/api-keys
  4. 点击「创建 API Key」
  5. 权限选「读写」
  6. 域名范围选「所有可访问域名」
  7. 默认域名留空不填
  8. 点击创建，复制生成的密钥（格式：AC-xxxxxxxxxxxxxxxx）

免费账户额度：
  - 每天 20,000 次 API 调用（足够注册几千个账号）
  - 同时最多 20 个邮箱（用完自动释放）
  - 261 个域名随机切换（防风控封禁）


================================================================
  第二步：安装依赖
================================================================

切记是要在你解压完之后的文件夹里面。
举个例子，就比如我现在的文件目录是这样子 D:\GhostReg，
然后点击上面的文件目录，把它改为 CMD 回车，就弹出命令行。

运行：

  pip install -r requirements.txt

等它装完就行了。会自动安装以下 5 个依赖：

  DrissionPage   — 浏览器自动化
  httpx          — HTTP 请求
  fastapi        — Web 控制面板后端
  uvicorn        — 服务器
  websockets     — 实时通信


================================================================
  第三步：启动程序
================================================================

1. 跟上一步一样，在 GhostReg 文件夹的地址栏里输入 cmd 回车
   （如果上一步的窗口还开着就直接用）
2. 输入以下命令，回车：

  python -m ghostreg

启动后会看到：

  ====================================================
    GhostReg — JetBrains 账号半自动注册机
  ====================================================
    控制面板: http://127.0.0.1:7860

然后浏览器会自动打开控制面板页面。
如果没自动打开，手动在浏览器访问：http://127.0.0.1:7860

================================================================
  第四步：配置 API Key（首次使用，只需一次）
================================================================

打开控制面板后，你会看到顶部有一个红色的提示框。

1. 把你在第一步获取的 API Key（AC-xxxxxxxx）粘贴到输入框
2. 点击「保存」按钮
3. 红色框变成绿色，显示「API Key 已配置，可以开始注册」

保存后永久生效！下次启动程序不需要重新配置。
API Key 保存在 output/settings.json 文件里。


================================================================
  第四步半：配置打码平台（全自动过验证码，可选）
================================================================

配置后勾选「全自动化过验证码」即可实现全程自动注册，不用手动过验证码！

【注册 YesCaptcha 账号】
  1. 打开 https://yescaptcha.com 注册账号
  2. 登录后在「个人中心」充值积分
     - 支持 微信支付 / 支付宝
     - 1 元 = 1000 积分，每次验证消耗 15 积分
     - 1 元 ≈ 注册 66 个账号
     - 建议充 2~3 元就够用了（可注册 130~200 个账号）
  3. 在「个人中心」复制你的 ClientKey

【在 GhostReg 中配置】
  1. 打开控制面板，找到「打码平台配置」区域
  2. 把 ClientKey 粘贴到输入框
  3. 点击「保存」
  4. 显示绿色「打码平台已配置」+ 当前余额

保存后永久生效！下次启动不需要重新配置。

【关于费用】
  - 全自动模式每注册 1 个账号消耗约 15 积分（¥0.015）
  - 1 元充值 = 1000 积分 ≈ 66 次验证
  - 3 元充值 = 3000 积分 ≈ 200 次验证
  - 不充值也能用：不勾选全自动，退回手动过验证码模式


================================================================
  第四步 B：协议注册机（推荐！速度更快）
================================================================

协议注册机是 v1.3 新增的「协议注册」Tab 页功能。
纯 HTTP 请求完成注册，不弹浏览器，速度比浏览器版快 5-10 倍。

【什么是协议注册？】
  - 不需要打开浏览器，纯后台运行
  - 单个账号 17-30 秒即可注册完成（浏览器版需要 3-5 分钟）
  - 支持最高 20 并发（配合 CF 代理池）
  - 同样需要 YYDS Mail API Key + YesCaptcha 打码平台

【使用步骤】
  1. 打开控制面板后，点击顶部的「协议注册」Tab 标签
  2. 设置注册数量（1-50）
  3. 设置并发数：
     - 不开代理池：建议 3（超过会触发 JetBrains 限频）
     - 开代理池：每 5 并发需 1 个 Workers（详见下方 CF 代理池说明）
  4. 设置密码（默认 QPalzmw123，仅限英文字母和数字）
  5. 点击「开始协议注册」
  6. 下方会实时显示每个任务的进度和结果

【注意事项】
  - 协议注册必须开梯子，且必须是虚拟网卡（TUN）模式！
    系统代理模式会触发腾讯验证码（不是 reCAPTCHA），会失败。
  - 推荐日本节点（网络质量好，单号 17 秒）
  - 美国节点也可以但较慢（单号 60-90 秒，SSL 偶尔波动）

【协议注册 vs 浏览器注册对比】
  - 协议注册：快（17-30s/号），省资源，适合批量
  - 浏览器注册：慢（3-5min/号），能看到过程，适合少量+需要绑卡


================================================================
  第四步 C：Cloudflare 动态 IP 代理池（可选，大批量推荐）
================================================================

如果你想一次注册很多账号（>3 个），强烈推荐开启 CF 代理池。
通过 Cloudflare Workers 获取免费的动态出口 IP，突破单 IP 限频。

开了代理池之后，20 个账号 90 秒就能全部注册完成！

【为什么需要代理池？】
  - JetBrains 会对同一 IP 限频：同一 IP 超过 3 个并发注册就会触发 429 错误
  - CF 代理池让每组任务走不同 IP，互不干扰
  - 实测：不开代理池 3 并发 = 极限，开代理池 20 并发 = 100% 成功

★★★ 重要风险提示 ★★★
  此功能会在你的 Cloudflare 账号下自动部署 Workers 脚本。
  此操作可能导致你的 Cloudflare 账号被封禁！
  强烈建议：用一个全新的、不重要的邮箱注册一个新的 CF 账号！
  不要用你的主力 CF 账号！注册 CF 完全免费，随便注册一个即可。

【配置步骤】
  1. 用不重要的邮箱注册 Cloudflare 免费账号：https://dash.cloudflare.com/sign-up
  2. 获取 Account ID：
     - 登录后点左侧菜单「Workers & Pages」
     - 右侧边栏找到 Account ID，复制
  3. 创建 API Token：
     - 点右上角头像 → My Profile（我的资料）
     - 左侧选 API Tokens（API 令牌）
     - 点 Create Token（创建令牌）
     - 找到 Edit Cloudflare Workers 模板，点 Use template（使用模板）
     - 直接点 Continue to summary → Create Token
     - 复制生成的 Token（以 cfut_ 开头）
  4. 在 GhostReg 控制面板的「协议注册」Tab 页：
     - 勾选「启用 Cloudflare 动态 IP 代理池」
     - 展开配置面板，填入 API Token 和 Account ID
     - Workers 数量：按需设定（每个 Workers 可承载 5 个并发）
       例：注册 15 号 → 3 个 Workers（15÷5=3）
     - 梯子代理地址：填你梯子的 HTTP 代理端口（必填）
       Clash/FlClash 默认一般是 http://127.0.0.1:7890
     - 点「保存并部署 Workers」
  5. 等待显示绿色的「Workers 部署成功!」
  6. 之后正常点「开始协议注册」，程序会自动使用代理池

【Workers 数量怎么选？】
  - 每个 Workers = 1 个独立 IP 池，可承载 5 个并发
  - 公式：Workers 数 = 注册数量 ÷ 5（向上取整）
  - 例：注册 10 号 → 2 个 Workers
  - 例：注册 20 号 → 4 个 Workers
  - 不确定的话就填 3，能覆盖 15 并发

【用完后清理】
  - 在配置面板点「删除 Workers」可以一键删除部署的脚本
  - 不删也没关系，CF 免费额度 100,000 请求/天，足够注册几千个账号


================================================================
  第五步：注册账号（浏览器版）
================================================================

配置完 API Key（和打码平台，如果要全自动的话）后，就可以开始注册了。

【设置密码】
  - 默认是 QPalzmw123
  - 只能用英文字母和数字！不要加 @ # $ 等特殊符号！否则注册会失败！

【选择浏览器】
  - Chrome 或 Edge，选你电脑上有的

【选择窗口数】
  - 直接输入数字，1-10 个窗口
  - 建议第一次先输 1 试试

【设置名字】
  - 可以点「随机名字」按钮自动生成
  - 多窗口注册时名字会自动加序号：比如 James, Jamesb, Jamesc

【全自动化过验证码（打码平台）】
  - 勾选 → 打码平台自动过验证码，全程无需手动操作（需要先配置 YesCaptcha）
  - 不勾选 → 手动模式，需要在浏览器中手动过验证码
  - 已测试 5 窗口并发全自动注册 5/5 成功

【自动跳转绑卡页（可选）】
  - 勾选后注册完成会自动跳转到 JetBrains Tokens 页面
  - 自动选择你指定的国家，弹出 Add credit card 表单
  - 支持 93 个国家，从下拉列表选择
  - 不勾选则注册完直接停在注册成功页

【三个按钮】
  - 「开始注册」 — 正常启动，清空上一次任务
  - 「强制新建」 — 不中断已有窗口，追加新的注册窗口（适合补开）
  - 「一键关闭所有浏览器」 — 关闭所有由程序管理的浏览器窗口


================================================================
  第六步：注册流程（每个窗口都是这样）
================================================================

1. 程序自动申请临时邮箱（从 261 个域名中随机选一个）
2. 弹出浏览器窗口，自动打开 JetBrains 注册页
3. 自动填写邮箱，自动点击 "I'm not a robot"
4. 验证码处理：
   - 【全自动模式】打码平台自动识别通过（约 15-30 秒），你什么都不用做
   - 【手动模式】在弹出的浏览器窗口里手动完成图片验证码（没有时间限制）
5. 验证码通过后自动点击 Continue 提交（有风控延迟，程序会自动等待）
6. 自动接收邮箱验证码并填入（通常 30-60 秒收到）
7. 自动勾选协议、填写密码和姓名，点击 Create account
8. （如果勾选了自动跳转）自动跳到 tokens 页 → 选国家 → 弹出绑卡表单

全自动模式下全程无需操作，5 个窗口并发约 3-5 分钟全部注册完成。
手动模式只需做第 4 步，其他都是自动的，没有时间限制。
注册完成后邮箱自动释放名额，不占用你的 20 个邮箱配额。


================================================================
  第六步半：批量自动登录
================================================================

如果你用协议注册机注册了账号，注册完没有保持在浏览器页面上。
需要登录时，不用一个一个手动登录了！用「批量自动登录」功能一键搞定。

【两种登录方式】

  1. 协议登录（推荐！秒级完成）：
     纯 HTTP 登录 + Cookie 注入浏览器。不需要自动化点按钮填表单，
     后台完成登录后直接打开已登录的浏览器窗口。
     15 个账号约 15-20 秒全部搞定！

  2. 浏览器登录（备用，兼容性好）：
     自动化填表单、点按钮登录，较慢（每个账号约 15-30 秒）。
     如果协议登录不可用（比如 JetBrains 改了 API），可以用这个。

【使用步骤】
  1. 在「浏览器注册」Tab 页中，找到「批量自动登录」面板
  2. 在文本框中粘贴账号列表，每行一个账号
     支持的格式（任选一种）：
       - 邮箱----密码     （如 abc@xxx.com----QPalzmw123）
       - 邮箱:密码        （如 abc@xxx.com:QPalzmw123）
       - 邮箱 密码        （如 abc@xxx.com QPalzmw123）
       - 直接从表格/CSV/JSON 复制粘贴也能自动识别
  3. 选择浏览器类型（Chrome / Edge）
  4. 设置并发数（1-15，默认 5）
  5. 如果需要登录后自动跳转绑卡页，勾选「登录后自动跳转绑卡页」并选择国家
  6. 点击绿色「协议登录（推荐，秒开）」或紫色「浏览器登录（慢）」
  7. 等待浏览器窗口弹出，已经是登录好的状态

【注意事项】
  - 最多同时登录 20 个账号（每个都会弹浏览器窗口）
  - 并发数可调（1-15），按电脑性能选择，推荐 5-10
  - 需要开梯子（登录需要访问 JetBrains）
  - 登录成功后浏览器窗口保留不关闭，可以继续用来填卡
  - 协议登录失败的账号不会残留浏览器窗口（自动清理）
  - 实测：15 并发协议登录 15/15 全部成功


================================================================
  第七步：一键填卡（绑定银行卡）
================================================================

注册完成后，如果需要给账号绑定银行卡，可以用「一键填卡」功能。

★★★ 重要：一键填卡只能识别通过本程序打开的浏览器窗口！★★★
  自己手动双击打开的 Chrome/Edge 无法被识别，必须用以下方式打开浏览器：

【打开浏览器窗口 — 三种方式】

  方式一（刚注册完）：
    注册成功后浏览器窗口会保留不关闭，直接用这些窗口即可。
    如果开了「自动跳转绑卡页」，窗口已经在 Add credit card 页面了。

  方式二（用批量自动登录，推荐！）：
    在「批量自动登录」面板粘贴账号 → 勾选「自动跳转绑卡页」→ 点击登录。
    登录完成后每个窗口自动跳到绑卡页面，直接就能一键填卡。

  方式三（手动打开浏览器窗口）：
    在控制面板的「一键填卡」区域顶部：
    1. 填写要打开的数量（比如 5）
    2. 选择浏览器类型（Chrome 或 Edge）
    3. 点击「打开浏览器」按钮
    4. 程序会自动弹出浏览器窗口，并打开 JetBrains 登录页
    5. 在每个弹出的窗口中手动登录你的 JetBrains 账号
    6. 登录后手动导航到 Add credit card（绑卡）页面
    7. 回到控制面板，点「刷新窗口列表」确认能看到窗口

【使用步骤】
  1. 在控制面板中找到「一键填卡」区域
  2. 点击「刷新窗口列表」，确认能看到你的浏览器窗口
  3. 填写银行卡信息：
     - 卡号（纯数字，如 4111111111111111）
     - 有效期（MM/YY，输入月份后会自动加 /）
     - CVV 安全码（卡背面 3 位数字）
     - 持卡人姓名（和银行卡上一致）
  4. 选择目标窗口（默认「所有窗口」，也可以选某个特定窗口）

【三个按钮】
  - 「一键填写」 — 把卡信息自动填入所有窗口的绑卡表单
  - 「一键清空」 — 清空所有窗口的绑卡表单（卡号/日期/CVV/姓名全部清除）
  - 「一键确认」 — 自动点击所有窗口的蓝色 Confirm 按钮提交绑卡

【推荐流程】
  1. 先用一键填写，填完检查浏览器窗口确认信息正确
  2. 如果有误，用一键清空，重新填写
  3. 确认无误后，点一键确认提交

【注意事项】
  - 浏览器窗口必须通过本程序打开（注册时自动打开的，或用「打开浏览器」按钮打开的）
  - 自己手动双击桌面图标打开的 Chrome/Edge 无法被识别！
  - 如果重新启动了 GhostReg（CMD 关了重开），之前没关的浏览器窗口仍然能被检测到
  - 填写/清空/确认操作 5 个窗口同时执行，15 个窗口约 12 秒
  - 打开浏览器 3 个同时打开，6 个窗口约 10 秒
  - 建议一次不超过 30 个窗口


================================================================
  第八步：管理已注册账号
================================================================

- 控制面板底部「已注册账号」表格会实时显示成功的账号
- 每条记录有：序号、邮箱、密码、注册时间
- 点「复制」按钮可以复制邮箱和密码
- 关闭程序重新启动后，历史记录还在！

【删除记录】
  - 每条记录右边有红色「删除」按钮，点击可删除单条
  - 表格左上角有 checkbox 全选框，勾选后点「删除选中」可批量删除
  - 删除后序号会自动重新编排
  - 删除操作会同步更新 output 文件夹里的 JSON 和 CSV 文件

结果文件位置：
  output/accounts.json  — 程序用的
  output/accounts.csv   — 可以用 Excel 打开
  output/settings.json  — API Key 配置（自动生成）


================================================================
  常见问题
================================================================

问：API Key 是什么？怎么获取？
答：YYDS Mail 的免费临时邮箱服务密钥。打开 vip.215.im/login 注册登录，
    然后到 vip.215.im/api-keys 创建一个「读写」权限的密钥，复制粘贴到
    GhostReg 控制面板保存即可。免费，不花钱。

问：API Key 需要每次都输入吗？
答：不需要！保存一次后永久生效，重启程序也不用重新配置。

问：提示 "API Key 未配置" 怎么办？
答：去控制面板顶部的红色提示框里粘贴你的 API Key 并保存。

问：验证码太难了过不了怎么办？
答：推荐使用全自动模式（打码平台），配置 YesCaptcha 后勾选全自动即可。
    如果用手动模式，没有时间限制，慢慢来。换个梯子节点可能会简单很多。

问：打码平台怎么充值？
答：打开 yescaptcha.com 注册登录，在个人中心充值。支持微信和支付宝。
    1 元 ≈ 66 次验证，建议充 2~3 元就够了。

问：打码平台余额用完了怎么办？
答：去 YesCaptcha 网站充值即可。也可以不勾选全自动，退回手动过验证码模式。

问：全自动注册一个账号消耗多少积分？
答：每个账号消耗约 15 积分（¥0.015），即不到 2 分钱。

问：浏览器弹出来了但卡住不动？
答：网络慢，页面还在加载。程序会自动重试（最多等 2 分钟）。检查梯子是否正常。

问：邮箱验证码收不到？
答：程序会自动轮询（最多等 10 分钟）。通常 30-60 秒就能收到。
    如果超时可能是网络问题，重新注册即可。

问：验证码填入后页面爆红 / 提示无效？
答：程序已加入逐位输入延迟，填完后会等 2 秒再提交。如果仍然爆红，可能是网络延迟，
    手动在浏览器里再输一遍即可。

问：密码有什么限制？
答：只能英文字母和数字，不能有特殊符号，否则注册失败。

问：可以同时开几个窗口？
答：最多 10 个。全自动模式下 5 个窗口并发已测试 5/5 成功。
    手动模式建议从 1-3 个开始，每个窗口都需要手动过验证码。

问：「强制新建」和「开始注册」有什么区别？
答：「开始注册」会清空上一次的任务重新开始。「强制新建」不清空，在现有任务基础上追加新窗口。
    适合中途想多开几个窗口的场景。

问：一键填卡点了刷新窗口列表没有窗口？
答：浏览器窗口必须通过本程序打开。如果之前注册的窗口已经关了，
    在「一键填卡」区域点「打开浏览器」按钮重新打开，登录后导航到绑卡页面即可。
    自己手动双击打开的 Chrome/Edge 不支持。

问：一键填卡能同时操作多少个窗口？
答：5 个窗口同时操作，不管多少个窗口都能处理。15 个窗口大约 12 秒，30 个大约 24 秒。

问：注册的账号保存在哪？
答：项目目录下的 output 文件夹里。accounts.csv 可以用 Excel 打开查看。

问：CMD 窗口可以关吗？
答：注册过程中不要关。注册完成后可以关。下次再开还能看到历史记录。

问：协议注册和浏览器注册选哪个？
答：推荐协议注册。速度快（17-30秒/号），不弹浏览器，适合批量注册。
    浏览器注册适合需要绑卡的场景（注册完直接跳绑卡页）。

问：协议注册提示"腾讯验证码"怎么办？
答：你的梯子不是虚拟网卡（TUN）模式。在梯子设置里切换到 TUN 模式即可。
    系统代理模式会被 JetBrains 检测，返回腾讯验证码（打码平台无法处理）。

问：CF 代理池会不会把我 Cloudflare 账号封了？
答：有可能！所以一定要用不重要的小号。用新邮箱随便注册一个 CF 免费账号，
    专门给 GhostReg 用，封了也不心疼。

问：CF 代理池部署失败怎么办？
答：检查 API Token 和 Account ID 是否正确。API Token 必须有 Edit Workers 权限。
    梯子代理地址必须填对（workers.dev 被墙，需要梯子才能访问）。

问：换了电脑 / 换了文件夹怎么办？
答：把整个 GhostReg 文件夹复制过去，重新 pip install -r requirements.txt 就行。
    API Key 和打码平台 Key 需要重新配置（保存在 output/settings.json 里，也可以一起复制过去）。

GhostReg/
  使用教程.txt             <- 你正在看的这个文件
  requirements.txt         <- Python 依赖列表
  ghostreg/                <- 浏览器注册 + Web 控制面板
    __init__.py
    __main__.py            <- python -m ghostreg 入口
    main.py                <- 启动服务 + 自动开浏览器
    server.py              <- Web 后端 + WebSocket + 填卡/协议注册/CF 代理池 API
    register.py            <- 8 步注册流程 + 填卡/清空/确认
    email_service.py       <- YYDS Mail 临时邮箱 API（261 个域名）
    captcha_service.py     <- 打码平台接口（YesCaptcha 全自动过验证码）
    captcha_solver.py      <- AI 验证码识别（备用，开发中）
    config.py              <- 配置 + API Key + 打码平台 + CF 代理池持久化
    proxy_pool.py          <- CF Workers 代理池管理（部署/健康检查/IP 分组）
    static/
      index.html           <- 控制面板网页（浏览器注册 + 协议注册 两个 Tab）
  protocol_reg/            <- 协议注册机（纯 HTTP，不弹浏览器）
    __init__.py
    __main__.py            <- python -m protocol_reg 入口（CLI 独立运行）
    client.py              <- HTTP 客户端（Chrome TLS 指纹 + Workers 代理）
    jb_api.py              <- JetBrains 注册 8 步 API 链
    worker.py              <- 批量并发调度 + 结果保存
  workers/
    ghostreg_proxy.js      <- CF Workers 代理脚本（自动部署到 Cloudflare）
  output/                  <- 注册结果 + 设置（自动生成）
    accounts.json          <- 浏览器版注册成功的账号（JSON）
    accounts.csv           <- 浏览器版注册成功的账号（Excel 可打开）
    protocol_accounts.json <- 协议注册机成功的账号（JSON）
    protocol_accounts.csv  <- 协议注册机成功的账号（Excel 可打开）
    settings.json          <- API Key 等配置（保存后自动生成）
