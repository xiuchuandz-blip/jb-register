🔑 通过邮箱更改密码
JetBrains 会向注册邮箱发送重置链接，建议梯子环境下适当加长超时
工作原理：系统会重新创建注册时使用的临时邮箱地址，然后向 JetBrains 请求发送密码重置邮件，自动读取邮件中的重置链接并完成密码修改。
协议注册机 — 纯 HTTP 极速注册
不打开浏览器，直接通过 HTTP 协议与 JetBrains API 通信完成注册。
速度：单账号 30-60 秒（浏览器版 3 分钟）  内存：5MB/任务（浏览器版 300MB/窗口）  并发：最高 20 路
需要已配置 YYDS Mail API Key + YesCaptcha 打码平台（与浏览器版共享配置）
协议注册控制
* 不开代理池：建议 3（超过会触发 429）
* 开代理池：每 5 并发需 1 个 Workers，最高已测 20 并发
* 仅限英文字母和数字
Cloudflare 动态 IP 代理池
⚠ 重要风险提示
本功能会在你的 Cloudflare 账号下自动部署 Workers 脚本用于代理请求。
此操作可能导致你的 Cloudflare 账号被封禁（违反 CF TOS）。
强烈建议：用一个全新的、不重要的邮箱注册一个新的 Cloudflare 账号，专门用于此功能。
不要使用你的主力 CF 账号！注册 CF 完全免费，随便注册一个即可。
通过 Cloudflare Workers 免费获取动态出口 IP，每 5 个并发共用 1 个 IP，突破单 IP 429 限频。
免费：只需注册 Cloudflare 免费账号，无需付费。注意：workers.dev 域名在大陆需要梯子访问。
📚 如何获取 API Token 和 Account ID？（点击展开教程）
第一步：注册 Cloudflare 账号
• 打开 https://dash.cloudflare.com/sign-up
• 用一个不重要的新邮箱注册（不要用主力邮箱！）
• 注册完成后登录 Cloudflare Dashboard

第二步：获取 Account ID
• 登录后点击左侧菜单 Workers & Pages（Workers 和 Pages）
• 在右侧边栏找到 Account ID，复制那串 32 位字符
• 或直接打开：Workers & Pages 页面

第三步：创建 API Token
• 点击右上角头像 → My Profile（我的资料）
• 左侧选 API Tokens（API 令牌）
• 点击 Create Token（创建令牌）
• 找到 Edit Cloudflare Workers（编辑 Cloudflare Workers）模板，点 Use template（使用模板）
• 直接点 Continue to summary（继续到摘要）→ Create Token（创建令牌）
• 复制生成的 Token（以 cfut_ 开头）
• 或直接打开：API Tokens 页面

第四步：填写梯子代理地址
• 如果你用的是 Clash / V2Ray / FlClash，默认 HTTP 代理端口一般是 http://127.0.0.1:7890
• 如果你不确定端口，打开你的梯子软件查看 HTTP 代理端口设置
• 这个地址是必填的，因为 workers.dev 域名在国内被墙了

第五步：点击「保存并部署 Workers」
• 程序会自动通过 Cloudflare API 把代理脚本部署到你的账号下
• 部署成功后会显示绿色的 "Workers 部署成功!" 和 Workers URL
• 之后勾选上方的"启用 Cloudflare 动态 IP 代理池"，开始注册时就会自动通过代理注册
